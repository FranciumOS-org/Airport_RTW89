# Credits

AirPort_RTW88 is built upon and inspired by the work of several open-source projects and communities.

## Linux rtw88

The Realtek RTL88xx hardware support used by AirPort_RTW88 is based on the Linux `rtw88` driver.

Original work belongs to Realtek Corporation, Linux kernel developers, and the contributors to `rtw88`.

Relevant derived source files retain their original SPDX licensing information.

## OpenIntelWireless — itlwm

AirPort_RTW88 uses concepts and implementation references from `itlwm`.

Special thanks to the OpenIntelWireless developers and contributors for their work on wireless support for macOS.

## OpenIntelWireless — AirportItlwm

AirportItlwm was used as an important reference for integration with Apple's AirPort/IO80211 networking stack, including controller lifecycle and interface behavior.

Reference material preserved under `tests/fixtures/airportitlwm-2.3.0` retains its original copyright and license notices.

## Apple

Some interfaces and headers used by this project originate from Apple open-source components and retain their applicable Apple license notices.

## MacKernelSDK

This project uses MacKernelSDK for macOS kernel development.

MacKernelSDK retains its own license and copyright information.

## Community

Thanks to the Linux wireless community, OpenIntelWireless, Hackintosh developers, testers, and everyone whose research and documentation made this project possible.
